# Offline USB deployment (Windows x64)

## What this package contains

The **GitHub Release asset** named `ConsoleCapture_v0.8.0_USB.zip` contains the editable Python program, `USB_START.bat`, the official signed Python 3.13.17 Windows x64 installer and predownloaded dependency wheels for 64-bit Python 3.10 through 3.14.

The **source code ZIP generated by GitHub** does *not* contain the installer or wheels. For USB deployment, download the release **asset**, not "Source code (zip)".

## Preparing the thumbdrive

1. Download the completed `ConsoleCapture_v0.8.0_USB.zip` GitHub Release asset on an internet-connected PC.
2. Extract the entire `ConsoleCapture_v0.8.0_USB` directory to the USB drive. Do not extract only `USB_START.bat`.
3. On the target Windows 10/11 x64 PC, run `USB_START.bat`.
4. If 64-bit Python 3.10–3.14 is installed, the launcher reuses it without an install prompt.
5. If no compatible Python is found, the launcher explicitly asks **Yes / No** before starting the bundled Python installer. **No** cancels without installing Python. The installer itself may request Windows confirmation and is installed per user.
6. The launcher creates `.venv` alongside the source and installs all needed packages using `--no-index --find-links offline\\wheels`; no network is contacted on the target PC.
7. Console Capture launches normally. The local `.venv` may be rebuilt when moving the USB to another PC.

## Notes

- This bundle is for **Windows x64**, not Windows ARM64 or 32-bit machines.
- The optional Python installer is provided by python.org and checked for a valid Python Software Foundation Authenticode signature before execution.
- Some corporate PCs block program execution from USB drives or software installation. Respect local IT policy; the launcher does not bypass security controls.
- A USB drive must be writable, with enough free space for the virtual environment and generated capture evidence.
- The launcher's wheels are strictly offline; if wheel files are missing, it exits rather than downloading packages.
- Captures, logs and reports may include sensitive customer information. Keep USB drives secure and encrypted if required by organizational policy.
- Hardware serial/COM and dark-mode visual tests should be performed on a real Windows machine before production use.

## Developers: rebuilding the offline ZIP

On a networked Windows x64 builder with Python and pip:

```powershell
python -m pip install --upgrade pip
python tools/build_usb.py --output ConsoleCapture_v0.8.0_USB.zip
```

The GitHub Actions release workflow uses this builder automatically and attaches the ZIP as an asset to the v0.8 prerelease after tests succeed. Do not store executable installer binaries inside the normal Git source tree.
